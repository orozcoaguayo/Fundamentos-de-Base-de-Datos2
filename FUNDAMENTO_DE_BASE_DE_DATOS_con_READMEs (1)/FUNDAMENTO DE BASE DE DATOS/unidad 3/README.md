# Unidad 3 — Modelo relacional e implementación

## Descripción

Esta unidad contiene documentos y recursos relacionados con la transformación y representación de un diseño de base de datos mediante esquemas relacionales y físicos. También incluye archivos SQL para trabajar con la estructura y datos de prueba.

## Actividades y archivos

### Tarea 3.1 — Esquema relacional
En `tarea 3.1/` se incluyen:
- `Documento-3.1.pdf`: documento de la actividad.
- `Esquema-relacional.pdf`: esquema relacional en PDF.
- `Esquema-relacional.png` y `Esquema-relacional.svg`: versiones de visualización.
- `Esquema-relacional.drawio`: fuente editable del esquema.

### Tarea 3.2 — Esquema físico y SQL
En `tarea3.2/` se incluyen:
- `Documento-3.2.pdf`: documento de la actividad.
- `Esquema-fisico.pdf`, `.png` y `.svg`: representaciones del esquema físico.
- `Esquema-fisico.drawio`: fuente editable del diagrama.
- `schema.sql`: script de definición de estructura.
- `datos-prueba.sql`: script de carga de datos de prueba.
- `validacion.sql`: consultas o instrucciones para validar la implementación.

## Cómo utilizar los scripts

Abre y revisa los archivos `.sql` en tu cliente de base de datos. Antes de ejecutarlos, verifica el motor de base de datos esperado y selecciona una base de datos de pruebas para evitar modificar información importante.
