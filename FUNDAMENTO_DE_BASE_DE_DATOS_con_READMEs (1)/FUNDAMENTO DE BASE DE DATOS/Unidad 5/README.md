# Unidad 5 — Álgebra relacional

## Descripción

Esta unidad presenta el álgebra relacional como fundamento formal de las consultas en bases de datos relacionales. Incluye operadores básicos y extendidos, su notación, interpretación y ejercicios de aplicación.

## Actividades y archivos

### Tarea 5.1 — Operadores del álgebra relacional básica y extendida
En `tarea 5.1/` se incluyen:
- `Documento-5.1.pdf`: documento de la actividad.
- `Informe-5.1.md`: informe técnico en Markdown.
- `Mapa-conceptual-operadores.pdf`: mapa conceptual en PDF.
- `Mapa-conceptual-operadores.png` y `.svg`: versiones de visualización.

### Tarea 5.2 — Ejercicios y consultas equivalentes
En `Tarea-5.2/` se incluyen:
- `Documento-5.2.pdf`: documento de la actividad.
- `algebra_relacional.py`: archivo Python para ejercicios o demostraciones de álgebra relacional.
- `consultas-equivalentes.sql`: consultas SQL equivalentes a expresiones relacionales.
- `consultas-relax.txt`: archivo auxiliar con consultas o notas.

## Temas principales

- Selección, proyección y renombrado.
- Unión, intersección, diferencia y producto cartesiano.
- Reunión (JOIN) y división.
- Operadores extendidos y funciones de agregación.
- Relación entre álgebra relacional y SQL.

## Cómo consultar y ejecutar

Consulta los documentos PDF y el mapa conceptual. Para ejecutar los archivos SQL, utiliza un SGBD compatible y revisa previamente el esquema y los datos requeridos. El archivo Python puede abrirse con Python 3.
