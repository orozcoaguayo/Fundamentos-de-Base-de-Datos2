# Unidad 4 — Normalización de bases de datos

## Descripción

Esta unidad aborda la normalización como proceso para organizar las relaciones de una base de datos, reducir redundancias y evitar anomalías de inserción, actualización y eliminación.

## Actividades y archivos

### Tarea 4.1 — Investigación y mapa conceptual de normalización
En `tarea 4.1/` se incluyen:
- `Documento-4.1.pdf`: documento de la actividad.
- `Mapa-conceptual-normalizacion.pdf`: mapa conceptual en PDF.
- `Mapa-conceptual-normalizacion.png` y `.svg`: versiones de visualización.

### Tarea 4.2 — Esquema normalizado
En `tarea4.2/` se incluyen:
- `Documento-4.2.pdf`: documento de la actividad.
- `normalized_schema.sql`: script SQL del esquema normalizado.

## Temas principales

- Propósito de la normalización.
- Organización de atributos y relaciones.
- Reducción de redundancia y prevención de anomalías.
- Aplicación del esquema normalizado mediante SQL.

## Cómo consultar

Revisa el documento PDF y el mapa conceptual de la Tarea 4.1. Para la Tarea 4.2, consulta el esquema SQL y ejecútalo únicamente en una base de datos de prueba compatible.
