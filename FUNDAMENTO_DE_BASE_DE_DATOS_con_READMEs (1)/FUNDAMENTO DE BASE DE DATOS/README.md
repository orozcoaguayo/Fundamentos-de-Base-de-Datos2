# Fundamentos de Base de Datos

Repositorio académico que reúne los trabajos y materiales desarrollados durante las **seis unidades** de la asignatura **Fundamentos de Base de Datos**.

## Datos del proyecto

- **Estudiante:** Kevin Anselmo Orozco Aguayo
- **Docente:** Rubén Riojas
- **Asignatura:** Fundamentos de Base de Datos
- **Contenido:** investigaciones, documentos PDF, diagramas, mapas conceptuales, scripts SQL y ejercicios prácticos.

## Cómo navegar

1. Abre la carpeta de la unidad que deseas consultar.
2. Lee el `README.md` de esa unidad para conocer su contenido.
3. Entra a la carpeta de cada tarea para consultar el PDF, diagramas, archivos Markdown o scripts correspondientes.

## Archivos y formatos

- **PDF:** reportes e investigaciones para lectura y entrega.
- **Markdown (`.md`):** documentación técnica y explicaciones.
- **SQL (`.sql`):** creación, carga, validación y consulta de bases de datos.
- **Draw.io (`.drawio`):** diagramas editables.
- **SVG / PNG / JPG:** mapas, esquemas e imágenes de apoyo.
- **Python (`.py`) y TXT:** ejercicios y archivos auxiliares.

## Nota

Los scripts SQL deben ejecutarse en el SGBD y versión compatibles con cada actividad. Revisa las instrucciones incluidas en el README de la unidad antes de ejecutarlos. Las capturas de ejecución y los enlaces a videos deben corresponder a evidencias reales del trabajo realizado.
