# Unidad 1 — Introducción a las bases de datos

## Descripción

Esta unidad presenta los fundamentos de las bases de datos y los sistemas gestores de bases de datos (SGBD). Se estudian conceptos esenciales, objetivos, usos, modelos de datos, criterios de clasificación y arquitecturas utilizadas para organizar y administrar la información.

## Actividades y archivos

### Tarea 1.1 — Fundamentos, objetivos y modelos de bases de datos
En `tarea 1.1/` se incluyen:
- `Documento-1.1.pdf`: documento de la actividad.
- `Investigacion-1.1.md`: investigación en formato Markdown.
- `Mapa-conceptual.svg`: mapa conceptual de los fundamentos.
- `Tabla-modelos.svg`: comparación visual de modelos de bases de datos.

### Tarea 1.2 — Clasificación y arquitecturas (ANSI/SPARC y SGBD)
En `tarea 1.2/` se incluyen:
- `Documento-1.2.pdf`: documento de la actividad.
- `Investigacion-1.2.md`: investigación sobre clasificación y arquitecturas.
- `Arquitectura-ANSI-SPARC.svg`: representación de la arquitectura de tres niveles.
- `Arquitectura-SGBD.svg`: esquema de la arquitectura funcional de un SGBD.
- `Cuadro-sinoptico.svg`: síntesis visual de la clasificación de bases de datos.

## Temas principales

- Conceptos de dato, información y base de datos.
- Objetivos y áreas de aplicación.
- Modelos jerárquico, de red, relacional, orientado a objetos y NoSQL.
- Clasificación de las bases de datos.
- Arquitectura ANSI/SPARC y componentes de un SGBD.

## Cómo consultar

Abre los PDF para revisar los entregables y los archivos SVG para visualizar los recursos gráficos. Los archivos Markdown contienen la versión textual de las investigaciones.
