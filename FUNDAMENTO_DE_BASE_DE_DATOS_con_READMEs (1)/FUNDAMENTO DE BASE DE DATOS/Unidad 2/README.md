# Unidad 2 — Modelado de datos

## Descripción

Esta unidad reúne los materiales de modelado de datos mediante diagramas. Se presentan representaciones conceptuales y de diseño para describir entidades, relaciones, atributos y elementos de un sistema.

## Actividades y archivos

### Tarea 2.1 — Modelo entidad-relación (ER/EER)
En `tarea 2.1/` se incluyen:
- `Documento-2.1.pdf`: documento de la actividad.
- `Diagrama-ER-EER.pdf`: diagrama en formato PDF.
- `Diagrama-ER-EER.png` y `Diagrama-ER-EER.svg`: versiones de visualización.
- `Diagrama-ER-EER.drawio`: archivo fuente editable del diagrama.

### Tarea 2.2 — Modelado UML
En `tarea 2.2/` se incluyen:
- `Documento-2.2.pdf`: documento de la actividad.
- `Diagrama-UML.pdf`: diagrama UML en PDF.
- `Diagrama-UML.png` y `Diagrama-UML.svg`: versiones de visualización.
- `Diagrama-UML.drawio`: archivo fuente editable.

## Cómo consultar

Consulta primero el PDF de cada tarea y después abre el diagrama correspondiente. Para modificar los diagramas, utiliza el archivo `.drawio` con diagrams.net (Draw.io).
