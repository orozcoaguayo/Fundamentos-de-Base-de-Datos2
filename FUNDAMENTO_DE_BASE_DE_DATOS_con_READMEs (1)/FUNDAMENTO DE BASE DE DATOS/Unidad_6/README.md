# Unidad 6 — Introducción al lenguaje SQL

## Descripción

Esta unidad desarrolla los fundamentos del lenguaje SQL y su aplicación para definir, manipular y consultar bases de datos relacionales. La parte práctica utiliza una base de datos de ejemplo llamada **TIENDA** y scripts orientados a MySQL 8.0.

## Actividades y archivos

### Tarea 6.1 — Sintaxis y clasificación de sentencias SQL
- `Investigacion_SQL.pdf`: investigación en PDF.
- `Tarea_6.1/Investigacion_SQL.md`: investigación en Markdown.
- Se estudian LDD/DDL (`CREATE`, `ALTER`, `DROP`, `TRUNCATE`) y LMD/DML (`INSERT`, `UPDATE`, `DELETE`, `SELECT`), incluyendo sintaxis, parámetros, restricciones y ejemplos.
- Se explica la distinción entre DDL, DML y DQL.

### Tarea 6.2 — Implementación de scripts DDL y consultas DML
- `Reporte_Tecnico.pdf`: reporte técnico de implementación.
- `Tarea_6.2/01_schema_ddl.sql`: creación de la base de datos y las tablas.
- `Tarea_6.2/02_data_inserts.sql`: inserción de datos de prueba.
- `Tarea_6.2/03_queries_dml.sql`: consultas, filtros, agrupaciones, agregaciones, JOIN y operaciones de modificación.
- `Imagenes/`: diagramas e infografías de apoyo.
- `Evidencias/README.md`: guía de capturas que deben obtenerse durante la ejecución.

## Requisitos y orden de ejecución

1. Contar con MySQL 8.0 y un cliente como MySQL Workbench.
2. Abrir y ejecutar `01_schema_ddl.sql`.
3. Ejecutar `02_data_inserts.sql`.
4. Ejecutar `03_queries_dml.sql`.
5. Tomar capturas auténticas de los resultados y agregarlas a `Evidencias/`.

**Importante:** las imágenes de apoyo no sustituyen las capturas reales de ejecución. Los resultados deben verificarse en el SGBD antes de presentarlos como evidencia.
